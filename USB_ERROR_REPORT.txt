USB BOOT FIX REPORT

Primary issue found:
- The OpenCore config had a malformed `DmgLoading` placement under `Misc > Boot`
- The repo had conflicting notes about `DevirtualiseMmio`
- The device is stalling at `EXITBS:START`, which is a standard OpenCore Boot Services hang

Fixes applied:
- `Misc > Boot > DmgLoading` removed
- `Misc > Security > DmgLoading = Signed`
- `Booter > Quirks > DevirtualiseMmio = false`
- `Booter > Quirks > RebuildAppleMemoryMap = true`
- `Booter > Quirks > SyncRuntimePermissions = true`
- `Booter > Quirks > ProvideCustomSlide = true`

What to do next:
1. Rename the external USB volume so it is not just a generic `(dmg)` label.
2. Boot the correct installer entry again.
3. Enable verbose boot output.
4. Capture the last log lines before the freeze to confirm whether a remaining ACPI or GPU issue is causing the hang.

This repo is still a hardware-specific Hackintosh EFI and should be treated as a validation project, not a ready-made universal build.
